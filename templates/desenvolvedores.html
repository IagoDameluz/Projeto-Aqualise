Sobre o projeto

O sistema AquaLise foi desenvolvido na linguagem Python, incorporando os conceitos abordados durante a disciplina. A interface web foi elaborada com o auxílio da inteligência artificial Claude e integrada ao framework Flask. O módulo AquaBot, por sua vez, utiliza a API do Gemini, da Google, para gerar recomendações personalizadas de economia de água a partir das informações registradas pelos usuários.
